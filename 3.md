### BROWSER CONSOLE AUDIT
A visually working page is NOT enough. Inspect browser console for:
- Hydration errors
- Runtime exceptions
- React warnings (missing keys, invalid props, etc.)
- Missing resources (404s)
- Failed module loads
- Invalid DOM properties (e.g., `strokeWidth` → `strokeWidth` in SVG)

Distinguish harmless dev-environment noise from actual application defects.

### BUILD VALIDATION GATE

If environment prevents build:
- Document exactly what failed
- Determine if environment limitation or application error
- Perform strongest alternative validation available
- Never silently skip validation

### SAFE JSX EDITING RULES
1. **Inspect before editing** - Read the complete component, understand the DOM tree
2. **Match every opening with closing** - Trace `<section>`, `<div>`, `<main>`, SVG elements, fragments, conditionals, maps
3. **Prefer component boundaries over deep nesting** - Extract small components rather than adding anonymous divs
4. **Don't blindly delete closing tags** - Parser happiness ≠ correct layout/animation/accessibility
4. **Animation safety** - Use CSS transitions/keyframes, IntersectionObserver, isolated client components; never let animation logic determine page structure existence
5. **Server-component safety** - Keep stable content server-rendered; use client components only where interaction requires them; no blanket `suppressHydrationWarning`, no setTimeout hydration hacks

- Do NOT modify application code to work around tooling issues

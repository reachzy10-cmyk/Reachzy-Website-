## 1. OVERALL VISUAL IDENTITY

### 1.1 Design Philosophy

Reachzy's visual identity is built on **dark-first, premium minimalism** — the site should feel like a carefully crafted professional brand, not a startup template. Every visual decision serves the story: Reachzy understands technology creators and brands.

**Core principles:**
- **Dark-first** — Near-black backgrounds with warm white text; not an inversion, a deliberate choice
- **Premium restraint** — Generous negative space, controlled color, typography-led hierarchy
- **Creative credibility** — Asymmetric layouts, meaningful imagery, purposeful motion over generic cards
- **Alive, not animated** — Motion communicates; it never decorates
- **Specific over polished** — Imperfect but real beats perfect but generic

### 1.2 Brand Personality Keywords

| Trait | Visual Expression |
|-------|-------------------|
| Technical | Mono type for data, precise spacing, clean lines |
| Human | Creator portraiture, editorial typography, warm tones |
| Credible | Verified metrics, real imagery, zero fake elements |
| Selective | One strong creator proof > fake roster of 50 |
| Modern | Dark mode native, fluid interactions, no skeuomorphism |

### 2.2 Color Application Rules

- **Never use pure black (`#000`) or pure white (`#fff`)** — use the OKLCH values above for depth
- **Accent Primary (cyan-blue)** — Brand actions, primary CTAs, key links, focus rings
- **Accent Coral** — Creator-side differentiation (hero eyebrow, secondary CTAs, creator metrics)
- **No gradients on text** — Solid colors only; gradients only for subtle atmospheric backgrounds
- **Borders at 1px** — Subtle, never heavy; `rgba(255,255,255,0.08)` equivalent in dark mode

## 9. INTERACTION & MOTION SYSTEM

### 9.1 Motion Principles

| Principle | Rule |
|-----------|------|
| **Purposeful** | Every animation communicates state change or hierarchy |
| **Respectful** | `prefers-reduced-motion: reduce` → disable all non-essential motion |
| **Fast** | Transitions `150-250ms`, no `>400ms` unless narrative |
| **Easing** | `cubic-bezier(0.22, 1, 0.36, 1)` (ease-out-expo) for entrance; `cubic-bezier(0.4, 0, 0.2, 1)` for state changes |
| **Staggered** | List items: `delay: index × 50ms`, max `300ms` total |

### 9.2 Page Load / Entrance

- **Hero content:** Fade up (`translateY(20px) → 0`, `opacity: 0 → 1`), `duration: 600ms`, stagger children `100ms`
- **Below-fold sections:** `IntersectionObserver` trigger at `rootMargin: "0px 0px -100px 0px"`
- **Section entrance:** Fade up `300ms`, stagger `50ms` per child
- **No skeleton loaders** — content is lightweight, prioritize font loading

### 9.3 Scroll-Based Effects

| Effect | Implementation | Pages |
|--------|----------------|-------|
| **Header solidify** | `scrollY > 100px` → add `bg-[var(--bg)]`, `border-b` | All |
| **Parallax hero portrait** | `transform: translateY(scrollY * 0.15)` (desktop only) | Home, Creator Profile |
| **Section reveal** | `IntersectionObserver` + CSS animation | All |
| **Metric count-up** | `IntersectionObserver` + `requestAnimationFrame` counter | Creator Proof sections |
| **Progress indicator** | Thin top bar, width = scroll progress | Long pages (For Brands, Creator Profile) |

### 9.4 Hover / Focus States

| Element | Hover | Focus (Keyboard) |
|---------|-------|------------------|
| Primary Button | `bg-[var(--accent-hover)]`, `transform: translateY(-1px)` | `ring-2 ring-[var(--accent)] ring-offset-2 ring-offset-[var(--bg)]` |
| Secondary Button | `bg-[var(--surface-elevated)]`, `border-[var(--accent)]` | Same ring |
| Card | `border-[var(--accent)]/50`, `shadow-lg`, `translateY(-2px)` | `ring-2 ring-[var(--accent)]` |
| Nav Link | `color: var(--fg)`, `border-b` accent | `outline-none ring-2 ring-[var(--accent)]` |
| Portrait | `scale(1.015)` | `ring-2 ring-[var(--accent)]` |
| Metric Chip | `bg-[var(--accent-subtle)]` | `ring-2 ring-[var(--accent)]` |

### 9.5 Micro-interactions

- **CTA icon (ArrowRight):** `translateX(4px)` on hover
- **Accordion chevron:** Rotate `180deg` on open (`transition-transform 200ms`)
- **Mailto links:** Subtle pulse on first view (once per session)
- **External links:** `target="_blank"` → small `ExternalLink` icon appears on hover

### 9.6 Reduced Motion

```css
@media (prefers-reduced-motion: reduce) {
  *,
  *::before,
  *::after {
    animation-duration: 0.01ms !important;
    animation-iteration-count: 1 !important;
    transition-duration: 0.01ms !important;
    scroll-behavior: auto !important;
  }
}
```
- Count-up animations → instant final value
- Parallax → disabled
- Stagger → removed

- **CTA copy from approved copy files** — No improvisation

## 14. ACCESSIBILITY

### 14.1 WCAG 2.1 AA Target

| Requirement | Implementation |
|-------------|----------------|
| **Color Contrast** | All text ≥ 4.5:1 (large text ≥ 3:1) — verified against dark palette |
| **Focus Visible** | Custom focus rings on all interactive elements |
| **Keyboard Navigation** | Tab order logical, skip link (`Skip to main content`) |
| **ARIA** | Native semantics first; ARIA only where needed (accordions, dialogs) |
| **Alt Text** | All images: descriptive, contextual (not "image of") |
| **Heading Hierarchy** | Single H1 per page, logical H2→H3→H4 |
| **Reduced Motion** | Full respect (Section 9.6) |
| **Touch Targets** | ≥ 44×44px on mobile |

### 14.2 Specific Implementations

- **Skip Link:** First focusable element, `sr-only` until focused
- **Accordion:** `<details>/<summary>` native, enhanced with smooth animation
- **Mobile Menu:** `role="dialog" aria-modal="true"`, focus trap, ESC to close
- **Forms (future):** Labels associated, error `aria-live="polite"`, autocomplete
- **External Links:** `rel="noopener noreferrer"`, icon + screen reader text "opens in new tab"

## 17. IMPLEMENTATION NOTES FOR 3.MD

### 17.1 Technical Stack Decisions

- **Framework:** Next.js 15 (App Router), React 19, TypeScript
- **Styling:** Tailwind CSS v4 (CSS-first config via `@theme inline`)
- **Fonts:** `next/font/google` (Newsreader, Geist, Geist Mono) — preloaded
- **Animations:** CSS-first (`@keyframes`, `transition`), Framer Motion only for complex orchestration
- **Icons:** `lucide-react` (tree-shaken)
- **Images:** `next/image` with `fill` + `sizes`, AVIF/WebP auto

### 17.2 Component Architecture

```
/components
  /ui              # Primitive: Button, Card, Accordion, MetricRow, Portrait
  /sections        # Page sections: Hero, Philosophy, ProcessSteps, Proof, DualPath, FinalCta
  /layout          # Header, Footer, SkipLink
  /creator         # CreatorCard, CreatorGrid, CampaignTable, VideoTable
```

### 17.3 Content Layer

- Copy imported from Markdown (or JSON) — **no hardcoded strings in components**
- `/lib/content/home.ts`, `/lib/content/for-brands.ts`, etc.
- Type-safe with Zod schemas matching approved copy structure

### 17.4 Performance Targets

- **LCP:** < 2.5s (hero portrait priority, font preload)
- **CLS:** < 0.1 (explicit image dimensions, font display optional)
- **INP:** < 200ms (minimal JS, CSS-first interactions)
- **Bundle:** < 150KB gzipped (no heavy libs)
